# commsIQ by Mediacorn Digital

Marketing site mirroring the Karix.com information architecture and UX patterns, rebranded as **commsIQ**.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Notes

- Contact / demo forms validate client-side only (no backend).
- Footer contact details are placeholders under Mediacorn Digital.
- Case studies are anonymized structural mirrors, not third-party client IP.
